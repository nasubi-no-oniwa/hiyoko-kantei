# ひよこ鑑定士だぜ

ひよこのお尻を見て、60秒でオスとメスに分ける。お尻のまんなかにポチ（突起）があればオスで左の青い箱、なければメスで右のピンクの箱へスワイプ。まちがえたら3秒止まる。

遊ぶ：https://nasubi-no-oniwa.github.io/hiyoko-kantei/

- `index.html` … ゲーム本体（1つのファイル）
- `database.rules.hiyoko.json` … ランキングのルール。GitHub に上げると自動で ft-red の `hiyoko` に反映（ほかのゲームのルールはそのまま）。リポジトリの Secrets に `FT_RED_SERVICE_ACCOUNT` が必要
- `test/rules-test.mjs` … ルールの試験（GitHub の上で試し用のデータベースを立てて試す）

## しくみ
- オスはお尻のまんなかに丸いポチ（生殖突起）がある。メスにはない。ポチの大きさは3通り
- リボン・ちょんまげ・モヒカン・帽子などのかざり、毛の色、ひとことの吹き出しは、オス・メスと関係ない（だますため）
- まちがえると、見分けるところを赤い点線で囲み、3秒止まる（そのあいだも時間は減る）。まちがえたひよこはそのまま箱に入る
- 60秒たつと場長が見に来る。箱にまざっていたら怒られる
- 結果に「プロ鑑定士の速さの何%か」を出す。プロは1時間に約1000羽（1分で約17羽）として計算
- ランキングは「鑑定した数」の順。同じ数なら、まちがいが少ない方が上。並べるための数 `k` は「数×1000＋999−まちがい」
- 始めた瞬間にサーバーの時刻を `hiyoko/runs/人` に書く。記録は、その時刻から55秒より前には載らない
- 消したい記録は、Firebase の `hiyoko/hidden/人のID` に `true` を入れるとランキングに出なくなる
- Xに投稿：リンクは結果ごとのページ `s/数.html`（0〜60羽。61羽からは `s/60p.html`・`s/80p.html`…）。日本語以外で遊んだ人は英語の画像 `s/en/` を使う
- 広告：スマホのときだけ、タイトル画面と結果画面のいちばん下に出す（なすびのお庭の決まりどおり）
